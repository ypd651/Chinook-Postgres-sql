## 📖 Descripción del Proyecto

Este taller tiene como objetivo practicar y dominar consultas SQL en PostgreSQL utilizando la base de datos **Chinook**, una base de datos de ejemplo que simula una tienda de música digital. Se abordan desde consultas básicas de filtrado y ordenamiento hasta consultas avanzadas con `JOIN`, funciones de agregación, y técnicas de optimización mediante índices.

### 🎯 Resultados de aprendizaje

- Formular consultas de negocio con PostgreSQL.
- Relacionar correctamente las tablas de Chinook.
- Justificar decisiones de optimización con evidencia obtenida mediante `EXPLAIN ANALYZE`.

---

## 🗄️ Sobre la Base de Datos Chinook

Chinook modela una tienda de música digital con las siguientes tablas principales:

| Tabla | Contenido |
|-------|-----------|
| `Artist` | Artistas |
| `Album` | Álbumes |
| `Track` | Canciones |
| `Genre` | Géneros musicales |
| `MediaType` | Tipos de archivo |
| `Customer` | Clientes |
| `Employee` | Empleados |
| `Invoice` | Facturas |
| `InvoiceLine` | Detalles de las facturas |
| `Playlist` | Listas de reproducción |
| `PlaylistTrack` | Canciones incluidas en cada lista |
